## Publication gate

Before a claim is published, set status to `Checked`, link the exact source/artifact, capture the source date/version, and approve precise wording. For product comparisons, prefer primary vendor documentation and state the checked date. For incident statistics, prefer company statements, court/regulator records, or directly attributable authoritative incident reporting. Claims based only on the hackathon booklet can be described as “the booklet states,” not presented as independently verified fact.
