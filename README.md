# IntentLock

IntentLock is a prototype specification for checking a multisig transaction's decoded intent before execution. It combines independent intent verification with an on-chain Safe guard and a narrowly scoped timelock for one administrative action.

The implementation requirements, trust boundaries, fixture catalog, demo procedures, and evidence rules are in [`docs/README.md`](docs/README.md). The project owner supplies the complete UI through Figma; this repository documents the system behavior and data contracts the UI consumes.

This repository currently contains specifications and planning documents. A documented behavior is not evidence that it has been implemented, tested, audited, or made production-ready.
